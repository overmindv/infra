# Стартовый каталог

`starter-catalog.json` содержит 64 оригинальных упражнения (по 8 на направление): SQL, ML, метрики/статистика, NLP, CV, LLM/RAG, Python, MLOps. Это вопросы с выбором ответа, которые автоматически проверяются платформой. Условия не скопированы с внешних сайтов. Ключи упражнений неизменяемые: изменение пакета не переписывает уже созданную версию задачи.

Внешний импорт: пользовательская подборка LeetCode + 50 отдельных SQL-задач + 10 алгоритмических. Источники:

- [SQL 50](https://leetcode.com/studyplan/top-sql-50/) — базовые и промежуточные SQL-темы.
- [LeetCode 75](https://leetcode.com/studyplan/leetcode-75/) — подготовка к алгоритмическим собеседованиям.
- [Подборка пользователя](https://leetcode.com/problem-list/oy4y273c/).
- [Deep-ML](https://www.deep-ml.com/) — дополнительный источник ML-практики; адаптер пока не реализован, автоматического импорта нет.
- [Kaggle Learn](https://www.kaggle.com/learn) — практические ML-курсы; автоматического копирования нет.

Внешние условия попадают в кандидаты на проверку. Проверяющий должен проверить условия использования источника, тему, условие и доступную конфигурацию проверки перед публикацией. Обход CAPTCHA, авторизации, платного доступа или лимитов не используется. Автоматического SQL-исполнителя в платформе пока нет.

## Запуск

`make up` запускает `catalog-bootstrap` после готовности gateway. Он не блокирует frontend; при недоступности внешнего сайта локальные упражнения остаются доступны. Скрипт работает через GraphQL от bootstrap-администратора, БД сервисов не читает.

- `make bootstrap` — повторить вручную на поднятом стеке.
- `make bootstrap-test` — автономные unit-тесты без Docker и сети.
- `docker compose logs catalog-bootstrap` — результат автоматического запуска.
- `CATALOG_BOOTSTRAP_ENABLED=false` — выключить всё наполнение.
- `CATALOG_IMPORT_EXTERNAL=false` — оставить только локальные упражнения.

Пароль берётся из `.env`; в журнал не записывается. State хранит только ключи/ID в отдельном volume. Блокировка не допускает двух одновременно работающих bootstrap. После прерывания между созданием и публикацией собственный draft находится по стабильному tag (в том числе после переименования). Опубликованные и архивные задачи не редактируются. Удалённые задачи при сохранённом state не восстанавливаются намеренно.

Внешний URL имеет стабильный idempotency key: рестарт возвращает существующее задание. Для failed/partial предусмотрено до трёх попыток при повторных запусках, с паузой не меньше часа после окончания предыдущей. До истечения паузы или после исчерпания попыток bootstrap возвращает exit 2. Дальнейший повтор доступен через интерфейс сбора с новым запросом; рестарт не создаёт бесконечный поток запросов к заблокированному источнику. `source_job` означает постановку/обнаружение задания, а не успешное скачивание; окончательный статус смотрите в разделе сбора задач.

Университеты (8), программы (30), курсы и темы уже загружаются миграцией `entities/202609040001_seed_catalog.sql`, программы имеют `university_id`. Это стартовый учебный каталог, а не синхронизация актуальных учебных планов вузов. Bootstrap не создаёт выдуманных связей для вручную добавленных программ. Новые самостоятельные темы упражнений не приписываются конкретному университету.
